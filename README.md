# Blix-A-Thon-IIT-bombay
Autonomous cube-sorting bot for Blix-A-Thon Coding Quest @ IIT Bombay Techfest — detects, picks &amp; places colored cubes into matching zones using color, IR &amp; ultrasonic sensors with a servo gripper. Zero manual control. 🏆 Won Most Efficiently Built Award @ IIT Bombay Techfest
