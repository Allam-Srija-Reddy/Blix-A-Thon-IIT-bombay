# Blix-A-Thon-IIT-bombay
Autonomous cube-sorting bot for Blix-A-Thon Coding Quest @ IIT Bombay Techfest — detects, picks &amp; places colored cubes into matching zones using color, IR &amp; ultrasonic sensors with a servo gripper. Zero manual control. 🏆 Won Most Efficiently Built Award @ IIT Bombay Techfest
🤖 Coding Quest — Blix-A-Thon 
🎯 What is the Task?
Participants must pre-program their bot before the challenge begins. The bot's task is to collect cubes from designated color zones and deliver them to their matching color zones. The bot must operate fully autonomously — no manual control is allowed during the challenge. Once started, the bot navigates the entire arena and completes the task on its own.  (Blixathon)
🧩 How the Arena Works
You first use the provided tape to mark the arena according to given sizes. Then every cube is placed into a mismatched color box to start with. For example:
Red cube is in Blue box
Blue cube is in Green box
Green cube is in Red box
Your robot must then sort them correctly — pick the red cube → place it in the red box, pick the blue cube → place it in the blue box, pick the green cube → place it in the green box.
